## ⚡ What Does This Tool Do?

Stop paying $50 to $100 per month for Apollo or ZoomInfo when you only need local B2B leads. **LocalLeads Kit** runs entirely on your local machine:

1. **Pulls Coordinates & Places:** Queries OpenStreetMap API for targeted business categories (e.g., plumbers, dentists, restaurants, realtors) in any city or postal code worldwide.
2. **Contact Extraction:** Deep-crawls target business websites for public email addresses, contact forms, and phone numbers.
3. **Deliverability Verification:** Integrates with ZeroBounce API to eliminate dead emails and avoid spam folders.
4. **Clean CSV Export:** Automatically segments output into:
   - `master_leads.csv`
   - `deliverable_emails.csv`
   - `phone_only_leads.csv`
   - `risky_review.csv`
